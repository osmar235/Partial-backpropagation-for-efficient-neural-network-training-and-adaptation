# Source-code map

The final Stage 6 entry point is:

`agrls_stage6a_cifar10_augmented_schedule.py`

The other `agrls_*.py` files are local dependency modules inherited from the
development sequence. They are retained so the final harness executes without
depending on unpublished project files.

The official Adan optimizer implementation used by the comparison is under
`third_party/Adan/` and retains its upstream Apache-2.0 license.
